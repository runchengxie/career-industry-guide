# 职业行业研究指南

这是一份面向职业选择的中国大陆行业研究静态网站。当前仓库为私有，网站尚未上线，也尚未启用 GitHub Pages。

本项目用来比较若干适合人文社科、市场营销、社会学等背景了解的行业入口。它帮助对照需求、岗位、门槛、风险和证据，不是就业保证，也不是完整的行业排名或求职中介。

## 当前状态

- 研究版本日期：2026-11-15（Asia/Shanghai）
- 已完成：三个行业样本的公开资料研究，以及本仓库中的设计说明
- 尚未完成：网站实现、内容数据入库、测试、部署和公开发布
- 请先审阅 `docs/superpowers/specs/2026-11-15-career-industry-guide-design.md`，确认规格后再进入实现

## 计划中的页面

- 首页：比较广告营销服务、养老服务、国内旅游服务三个研究样本，并按岗位方向筛选
- 行业页：统一说明定义、需求证据、适合岗位、门槛、风险和来源
- 岗位页：说明日常工作、可准备的作品，以及核验状态，并链回所属行业
- 来源与方法页：记录口径、日期、引用和未核实问题

页面不提供缺乏依据的综合评分，也不编造集中度、在招职位或薪资。先前对公开招聘的核验尚未完整，站点必须标明这一限制。

## 使用与贡献

实现获准后，本仓库将采用静态站点方案，内容数据与界面分离。在此之前，请不要把本仓库当作已发布产品来引用。原始研究提示词、个人隐私材料和未公开附件不应上传到本仓库。
