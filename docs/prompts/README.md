# 研究提示词

这两份提示词是本站研究的起点：一份设定任务（研究哪些行业、参考哪些渠道、用哪些标准），一份规定分析方法和交付格式。收录在这里，是为了让读者能复现研究流程，或改写后用于自己的调研。

- [industry-research-brief.md](industry-research-brief.md)：任务设定，三条要求和对应的渠道与价值标准。
- [industry-analysis-agent.md](industry-analysis-agent.md)：分析专家提示词，覆盖工作原则、范围界定、来源核验、规模测算、产业链、竞争格局、情景判断和报告结构。

## 转换与脱敏

两份文件原为 WPS Word 文档（`行业调查prompt.docx`、`Agent搭建prompt.docx`，创建于 2026-11-13）。这里的内容由文档正文提取后转为 Markdown：

- 正文措辞未改写，也没有增删要求。只做排版转换：补了一个文档标题，`一、`～`九、` 章节转为二级标题，原有编号清单保留为有序列表，复合增长率公式转为代码块。
- 标点做了统一：半角逗号改为全角逗号，括号内的并列项改用顿号；`industry-research-brief.md` 的两组条件改为嵌套列表。
- 两处机构名写作正式名称：“中国物流与采购联合协会”改为“中国物流与采购联合会”，“互联网行业协会”改为“中国互联网协会”。
- 原始 `.docx` 没有入库，其文档属性因此不在本仓库中：作者昵称、编辑软件账号标识、创建与修改时间、软件版本。
- 正文不含手机号、邮箱、身份证号、地址或第三方人名。

## 与站点口径的关系

`industry-research-brief.md` 要求“排行前十的行业”，而站点只取三个样本做结构验证，不排名、不打分，也不把行业增长写成就业结论。这是有意的收窄，理由见[设计说明](../superpowers/specs/2026-11-15-career-industry-guide-design.md)。提示词保留原样，不据此改写站点结论。

## 未收录的内容

研究过程中的原始对话、个人隐私材料和未公开附件不收录，也不在本站点发布。
